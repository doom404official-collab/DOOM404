# DOOM404 Website
Static V1 website for DOOM404.

## Deploy
Upload `index.html`, `styles.css`, `script.js`, and the final Litepaper PDF to the repository root. Vercel can deploy this as a static site with Framework/Application Preset: Other.

## Important
The Litepaper button expects a file named `DOOM404_Litepaper_v1.0.pdf` in the repository root.
Review all official links and token/contract information before public launch.
