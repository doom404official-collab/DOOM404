# GLITCH TEE — selected front/back design v0.2

## User-approved creative direction
Reference: user-provided black oversized GLITCH TEE front image, followed by user instruction to use the DOOM404 red-hooded mascot on the back.

### Front
- Black oversized tee, crew neck.
- Centered white DOOM + crimson 404 wordmark high on chest, with restrained micro-tagline beneath.
- Two vertical, thin red circuit/glitch columns framing the torso (not full-bleed across seams).
- Red graphic detail on sleeve(s) only if supplier supports sleeve printing for the chosen garment/size.
- Maintain generous negative space; no oversized front mascot.

### Back
- Hero illustration of DOOM404 red-hooded robotic mascot with illuminated red scanner eye.
- Red digital interference and restrained framing lines.
- DOOM404 / FIND THE GLITCH wordmark below mascot, scaled to remain legible.
- Avoid tiny unreadable labels and decorative microtext in final print file.

### Critical production split
A. Front chest logo: separate artwork layer.
B. Front vertical glitch lines: separate artwork layer. Whether this can be printed as one large front DTG design depends on the official product placement template. Do not assume all the way to hem.
C. Back mascot: separate transparent artwork layer.
D. Sleeve mark: separate optional placement, disabled until confirmed.
E. Neck label: separate optional branding, disabled until supplier support confirmed.

### Production gates
- Exact supplier SKU and color/size variant, placement names, template dimensions, safe-zone boundaries and minimum DPI must be recorded.
- Confirm AS Colour 5082 or select an equivalent garment with verified placements.
- Confirm front design can fit inside the actual front print area without crossing garment seams.
- Confirm back artwork placement clears collar and side seams.
- Convert text to paths, ensure no unsupported SVG filters/patterns remain in final export, and export transparent sRGB PNG to template specifications.
- Inspect physical sample before enabling checkout.
- Current previously created SVGs are *concept illustrations*, not faithful reproductions of the approved reference; update them before production.

## Acceptance criteria
1. Front visually follows supplied reference: centered logo, restrained red circuitry and sleeve motif.
2. Back features the red-hooded mascot as dominant graphic.
3. Front and back files can be independently submitted to the supplier.
4. All optional print zones are explicitly gated by supplier validation.
5. Store preview and production art show the same composition.
6. No token contract addresses.
