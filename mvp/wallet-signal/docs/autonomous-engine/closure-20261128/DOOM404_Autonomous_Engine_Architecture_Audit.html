Deterministic architecture

Mint/program → bounded creation evidence → supported role decoder → creator/current and historical accounts → bounded token history with continuation → protocol-aware event proof → semantic instruction deduplication → exact raw ledger and partial-history status → atomic observation/evidence persistence. Parallel independent branches share durable admission/provider budgets. No LLM selects runtime investigations.

Persistence and evidence protection

Immutable verified creator evidence is appended atomically with normal CAS finish. Qualification evidence has its own namespace and never reads or overwrites production token-specific cache. Dynamic balances/authorities/controls are observed again. Unfinished history uses15-second continuation expiry; bounded completed windows do not mean lifetime complete. Raw receipt cache/private cursors are stripped from public reports. Append-only role restrictions and 256KB normal observation cap remain enforced.
