# DOOM404 AI Media Agent — isolated browser MVP

Open `index.html` in a browser or serve this directory as static files. No dependencies or secrets.

## Implemented
- Responsive black/red risk intelligence interface
- Three educational, explicitly simulated scenarios
- Presenter scripts, evidence checklists, X-ready draft posts
- Copy action, keyboard-friendly native controls
- No publishing or live scanner calls

## Safety / data contract for next sprint
A future real episode must include: mint, chain, observation timestamp, RPC slot, source provider, exact transaction signatures/account links, calculation method, confidence and unresolved claims. Never label wallets independent without proof. Never infer wash trading from volume alone. Require human editorial approval before publishing. Reject an episode if the evidence is absent or stale.
